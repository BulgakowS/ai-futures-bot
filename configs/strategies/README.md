# Майбутні пресети стратегій

Тут згодом зберігатимуться версіоновані пресети Trend Following, Pullback і Breakout після перевірки контракту стратегій, backtest і forward paper тестів. Зараз конфігурацій немає; жодні параметри не позначені як рекомендовані або прибуткові. Див. [специфікацію стратегій](../../docs/STRATEGIES.md).
