## REST: підтверджений доступ

Default base нового адаптера `https://api.mexc.com`; `https://contract.mexc.com` також відповів на legacy public paths. Base configurable з allowlist. Усі запити GET, без ключів; success потребує HTTP success і `success=true, code=0`.

| Path | Live probe | Час/поля | Документований ліміт |
|---|---|---|---|
| `/api/v1/contract/ping` | Обидва hosts | data server epoch ms | Окремо не звірено |
| `/api/v1/contract/detail/country?symbol=BTC_USDT` | api.mexc.com | Object правил | 10 / 2s |
| `/api/v1/contract/detail?symbol=BTC_USDT` | Обидва hosts | Legacy object, 80 полів | Використовувати актуальний country path |
| `/api/v1/contract/ticker?symbol=BTC_USDT` | Обидва hosts | lastPrice/bid1/ask1/fairPrice/indexPrice/holdVol/fundingRate/timestamp ms | 10 / 2s |
| `/api/v1/contract/kline/BTC_USDT?interval=Min1` | contract.mexc.com | Parallel OHLCV arrays, time s | 20 / 2s |
| Той самий kline, Min5 і Min15 | api.mexc.com | По 2000 точок | 20 / 2s |
| `/api/v1/contract/funding_rate/BTC_USDT` | Обидва hosts | rate/collectCycle/nextSettleTime/timestamp ms | 20 / 2s |
| `/api/v1/contract/funding_rate/history?symbol=BTC_USDT&page_num=1&page_size=3` | contract.mexc.com | resultList rate/settleTime ms/collectCycle | 20 / 2s |
| `/api/v1/contract/depth/BTC_USDT?limit=5` | contract.mexc.com | asks/bids/version/timestamp, cts=null | Окремо не звірено |

Limits — документовані ceilings, не load-tested. MVP локальна політика ≤2 REST requests/s сумарно, backoff/jitter, Retry-After і 429/5xx handling.

Candles: `start/end` Unix seconds, max 2000; сегментувати історію. Intervals Min1/Min5/Min15/Min30/Min60/Hour4/Hour8/Day1/Week1/Month1. Live має `realOpen/realClose/realHigh/realLow`, що відрізнялися від OHLC; не підміняти ряд. `vol` і WS `q` — contracts, base volume=contracts×contractSize, amount=quote turnover. Немає підтвердженого final flag: поточна свічка provisional, final після interval end за server time та REST reconciliation. Не підміняти source_time received_at.

S11/M1 read-only перевірка [офіційної Candlestick Data](https://www.mexc.com/api-docs/futures/market-endpoints/get-candlestick-data) через gstack `/browse` **2026-10-19 ~07:15 UTC**: `GET /api/v1/contract/kline/{symbol}`, `Hour4`, `start/end` Unix seconds, max 2000, описаний rate limit 20/2s. У переліку response є time/open/close/high/low/vol і приклад `amount`/`real*`; окремого final flag немає. Висновок про finality після close за server time — наша консервативна політика, не біржова гарантія незмінності. Real API GET у M1 не виконувався.

## BTC_USDT: snapshot правил, не constants

Лінійний USDT perpetual: base BTC, quote/settle USDT, futureType=1, state=0, positionOpenType=3 (isolated/cross), apiAllowed=true. Це не дозвіл Live.

| Поле | Live значення |
|---|---|
| contractSize | 0.0001 BTC/contract |
| priceUnit / priceScale | 0.1 USDT / 1 |
| volUnit / volScale / minVol | 1 contract / 0 / 1 contract |
| maxVol / limitMaxVol | 400000 / 2500000 contracts; mode-specific caps не сплющувати |
| minLeverage / maxLeverage | 1 / 500; paper cap має бути нижчим |
| makerFeeRate / takerFeeRate | 0 / 0.0002; feeRateMode=NORMAL, feeRateType=BASE |
| maintenanceMarginRate / initialMarginRate | 0.001 / 0.002; riskLimitMode=CUSTOM, 6 riskLimitCustom tiers |
| liquidationFeeRate | 0.0004 |

Canonical quantity=contracts; quantity_base=contracts×contractSize; notional_quote=quantity_base×price. Parse `json.loads(text, parse_float=Decimal)`, serialize decimal strings; round за priceUnit/volUnit, не лише scale. Rules з raw snapshot/hash/version і received_at; unknown або змінені rules/state блокують нові ордери до валідації.

Fees — public instrument snapshot, не user/VIP/promotion rate. Docs example taker=0.0001 відрізняється від live=0.0002. Paper зберігає applied rate/source/override. Історичні fees не підтверджені; backtest позначає configurable assumption.

Funding snapshot: collectCycle=8 hours, rate=-0.000001, bounds ±0.0018, nextSettleTime=1791993600000 (2026-10-14 16:00 UTC). Поточна ставка не фінальна settlement rate. History probe: 3 records, totalCount=1620; повна глибина/gaps не перевірені. Нарахування за підтвердженим history settlement, idempotency `(portfolio_epoch,symbol,settle_time)`; missing rate=pending/missing, не домислювати. Розклад брати з endpoint, не hardcode 8h.

## WebSocket

`wss://contract.mexc.com/edge`, public login не потрібний. JSON `{"method":"ping"}` → channel pong, data epoch ms. Docs рекомендує ping кожні 10–20s, disconnect після 1 minute без ping. MVP policy 15s ping, fail stale при disconnect/timeout, backoff/jitter reconnect.

| Subscribe method | Push contract | Статус |
|---|---|---|
| sub.ticker, param symbol | push.ticker; data timestamp ms, ticker fields; ≈1s коли є trades | Live ack+push |
| sub.kline, param symbol+interval Min1, gzip false | push.kline; data t s/o/c/h/l/q/a, outer ts ms | Live ack+push |
| sub.funding.rate, param symbol, gzip false | push.funding.rate | Docs only; sample rate суперечить field table fundingRate, REST authority |
| sub.deal, param symbol | push.deal array p/v/T/O/M/i/t/cts | Docs only; compress=true aggregation за замовчуванням, не gzip |
| sub.depth, param symbol | push.depth asks/bids/version/cts, outer ts, 200ms | Docs only; incremental sequence |

8s smoke: pong, rs.sub.ticker=success, rs.sub.kline=success, push.kline і push.ticker. Не перевірено reconnect, binary/gzip, довгий потік, depth/funding WS. Ticker/kline не мають global sequence: dedupe candle `(exchange,symbol,interval,window_start)`, update payload hash, один сигнал на reconciled final.

Depth docs: subscribe/buffer → REST snapshot → versions строго +1, skip ≤last, absolute quantities, zero deletes; gap → depth_commits/{symbol}/1000 або snapshot. Commits ще не probe-tested. Третій depth tuple element описаний неоднозначно; зберігати raw, до додаткової перевірки використовувати лише price і друге поле contracts. Не fill через book із gap.

## Python handoff та межі

- Instrument `MEXC:BTC_USDT:PERPETUAL`, exchange mexc, kind linear_perpetual. timezone-aware UTC; відрізняти epoch s/ms.
- Event: exchange/instrument_id/event_type/source_time_utc/received_at_utc/sequence_or_cursor/payload/quality_status/raw_ref. Candle window start окремо від event time; causal ID/config version на межі журналу.
- Methods: server_time, contract_rules, ticker, candles(interval,start,end), funding_current, funding_history; WS ticker+kline. Rules/time/snapshot при старті; REST reconciliation після reconnect. Match exact symbol; contract info object/list перевіряти явно.
- Fail closed на stale/disconnect/schema mismatch/arrays різної довжини/unknown rules/state/HTTP або application errors. holdVol=поточний OI contracts. Історичні OI/spread/book/fees та точна біржова ліквідація не підтверджені.
- TTL ticker=5s, rules refresh=1h, max clock skew=2s — configurable стартові припущення для fault tests, не MEXC гарантії.
- S10G (2026-10-16): додатковий 120-секундний read-only зріз локального public WS cache дав 109 проб, ticker source age p99 4.729 с/max 5.052 с, один `ticker_stale`; крок `source_time` p50 3.003 с/max 3.865 с. Цей короткий ряд не доводить SLA або достатній довгий хвіст для нової TTL. Ticker TTL лишається 5 с; короткі перевищення блокують Paper entry, а окрема затримка confirmation стосується лише alert. Доказ: `docs/evidence/paper-public-quiet-{summary-,}2026-10-16.json*`.
- MVP припущення: BTC_USDT, isolated one-way paper, 1000 USDT, 1m/5m/15m, conservative configurable risk. Користувач окремо ці параметри не погоджував; показувати defaults у config/UI.
- Приватний MEXC broker відсутній у runtime; Live gate закритий.

## S15 isolated API maker 0% assessment, 2026-10-20

`ai_futures.mexc_api_maker_gate` — лише pure metadata/parser contract, без HTTP, credential, broker чи active API/worker/Settings wiring. Це **інший** фільтр, ніж S14 public 0/0 promo candidates: exact-symbol public Contract Info має свіжий (локальний `observed_at` ≤5 хв) active USDT linear perpetual, `apiAllowed=true` і додатні `contractSize/priceUnit/volUnit/minVol/maxVol` з локальним rules digest. Public `isZeroFee*`, `makerFeeRate` і `takerFeeRate` не визначають account API eligibility; зокрема public taker 0 не потрібний.

Assessment вимагає окреме account-bound evidence з результатом strict S13 `NORMAL` fee parser, `realMakerFee=Decimal(0)` та fee snapshot ≤5 хв. Ненульовий `realTakerFee` допустимий і повертається як окремий тариф. Додатково потрібне письмове **саме MEXC-issued** підтвердження для цього account+symbol, де прямо охоплені Futures **API maker** trades попри загальне виключення API users у [0-Fee Fest terms](https://www.mexc.com/zero-fee): issuer/channel, reference, SHA-256 artifact, exact scope/rate, issued/reviewed/expiry і reviewer reference. Відсутність, mismatch, майбутня дата, expiry, зміна maker rate або stale snapshot дають deny. Bare boolean чи S14 promo flag не є підтвердженням.

Pure gate перевіряє **форму metadata**, а не справжність листа MEXC чи належність fee response конкретному account. `account_binding_sha256` і `artifact_sha256` потребують незалежної позакодової перевірки первинних джерел; жодного способу автоматично отримати/верифікувати таке MEXC підтвердження не встановлено. У користувача його зараз **немає**, тому реальний результат — fail-closed; mock positive у тесті не є account eligibility. 0% maker не гарантує нуль кожного fill: taker fill може оплачуватися за taker rate, funding і spread залишаються; post-only/limit semantics майбутнього broker треба окремо звірити з офіційною документацією. Stage 8/10 Live gates і фактичні deal fees не перевірені. [Sanitized evidence](evidence/mexc-api-maker-gate-2026-10-20.json).

**Висновок для політики maker 0%:** `type=2` є задокументованим способом запитати Post Only, але документація не дає достатнього доказу поведінки immediate-cross, кожного часткового fill і фактичного fee. Майбутній broker має зберегти причинний intent/`externalOid`, після timeout/невідомого create або cancel **блокувати новий entry і reconciliation**, query за external ID/order ID та зіставити deals, fees і позицію; без сліпого retry. Фактичний `fee` і taker classification кожного deal треба зіставляти з account-specific `NORMAL` maker rate і окремим MEXC-issued письмовим API-maker-0 підтвердженням S17. Будь-який taker deal або невідома класифікація — fail closed, навіть якщо take rate може бути ненульовим. Це design requirement, не реалізований broker чи біржова гарантія.

До Live потрібна окрема офіційна/контрольована перевірка crossing/rejection і partial-fill/cancel behavior, shape per-fill marker, externalOid uniqueness/idempotency/retention, unknown-outcome reconciliation та Stage 8/10. Для майбутнього pilot числові per-pair і сукупний **full notional** (не margin), leverage, SL/TP% і daily loss limits користувач задаватиме в bot settings; сервер має їх валідувати, а unset значення блокувати Live. Порогів за замовчуванням немає; runtime і Live gate не змінено.

## S23 generic USDT-M research universe, 2026-10-21

Користувач скасував вимогу «зони 0 комісій» і письмового підтвердження 0% maker. Поточний майбутній universe — **усі** active `state=0`, perpetual `futureType=1`, `apiAllowed=true`, `baseCoin_USDT` з `quoteCoin=settleCoin=USDT`, включно зі stock/TradFi; `typeLabel` і public `isZeroFee*`/fee rates не визначають членство. Це замінює S14/S17/S19 zone shortlist як напрям відбору й S15 zero-maker exception як Live передумову. Історичний `mexc_api_maker_gate.py` залишено не підключеним до активного runtime, його `conditions_met` не слід використовувати як чинний Live gate.

Офіційні [Contract Info](https://www.mexc.com/api-docs/futures/market-endpoints/get-contract-info) та [REST Ticker](https://www.mexc.com/api-docs/futures/market-endpoints/get-ticker-contract-market-data) повторно прочитано через gstack `/browse` **2026-10-21**. Перший документ описує optional `symbol`, `state`, `futureType`, `apiAllowed`, `baseCoin/quoteCoin/settleCoin`, `typeLabel=1` TradFi / `2` stock; другий — optional `symbol`, `bid1/ask1`, `amount24` і trade `timestamp`. Обидва вказують 10 запитів / 2 с для відповідного endpoint. Документовані приклади `data=object` для exact symbol; повний no-symbol list відомий лише з минулих bounded probes, тому новий код не виконує мережевих запитів і приймає caller-supplied JSON/evidence. Біржовий effective time, повнота no-symbol catalog і валюта `amount24` не доведені.

`mexc_usdt_research.parse_public_usdt_catalog` перевіряє envelope/body cap 8 MiB, точний symbol/base/quote/settle, enum-и активності та API permission, не читає promotional fee fields. Дублікати, невідомі USDT rows або невалідний envelope роблять каталог непридатним для відбору. Локальний UTC `observed_at` і explicit TTL потрібні для research freshness. `select_usdt_research_shortlist` використовує тільки caller `TickerEvidence` з Decimal bid/ask/`amount24_raw`, UTC source/receive time, explicit spread/age policy та `max_pairs≤3`. Missing, stale, crossed, nonpositive й wide ticker відхиляються для відповідного символу; duplicate/foreign ticker відхиляє batch. Сортування: спадання raw `amount24`, зростання Decimal midpoint spread bps, symbol. Raw turnover не вважається доведеним USDT notional або виконуваною ліквідністю. Результат завжди `trade_ready=false` і позначає потребу у depth validation, свіжому authenticated account fee та cost-aware shared Risk Engine.

Майбутній Live entry дозволений лише через перевірений Post Only maker intent; захисні reduce-only виходи окремо резервують можливу taker-комісію. Для fee/cost risk gate потрібні account-specific maker/taker snapshot і фактичні deal fees, перевірені depth/units/slippage, funding, повний exposure та pending intents, а також Stage 8/10, числові pilot limits і окремий дозвіл на Live. Це вимоги, **не** реалізовані broker, order/reconciliation чи доказ Post Only semantics. Синтетичний research ranking не доводить прибутковість або придатність до реальної угоди.
