# AI Futures Trading Platform

Git remote `origin`: [BulgakowS/ai-futures-bot](https://github.com/BulgakowS/ai-futures-bot).

Локальна платформа для дослідження ф'ючерсних стратегій на ринкових даних MEXC. Основний режим — **Paper Trading**: ринкові дані надходять з біржі, а ордери та баланс є віртуальними. Проєкт перебуває на етапі специфікації: реалізації, контейнерів, ключів і запущеної торгівлі ще немає.

## Ціль

Користувач обирає інструмент, створює віртуальний портфель і бота, бачить живі дані, рішення стратегії та AI, перевірку ризику, віртуальні виконання і результат. Кілька ботів можуть паралельно порівнюватися на тому самому потоці даних. Live Trading є майбутнім окремим етапом і за замовчуванням технічно заблокований.

## Прийняті рішення

- Один репозиторій, модульний Python backend і окремий Next.js frontend; локальний запуск планується через один Docker Compose з кількома контейнерами.
- Python/FastAPI, PostgreSQL, Redis, Next.js/React/TypeScript, Tailwind CSS, shadcn/ui, Lightweight Charts, OpenAI API.
- Публічні дані MEXC мають дозволяти роботу Paper Trading без торгового API-ключа, якщо це підтвердить перевірка актуального API.
- Кожен торговий намір проходить незалежний Risk Engine. AI не має прямого доступу до брокера.
- Paper, backtest і майбутній live користуються спільними правилами сигналів і ризику, але окремими адаптерами виконання та ізольованими обліковими книгами.
- Інтерфейс простий на першому рівні, з режимами Simple / Advanced / Expert; українська й англійська мови, темна тема, мобільна адаптація.

## Структура папок

```text
apps/web/                   # майбутній Next.js frontend
services/api/               # майбутній FastAPI API
services/trading/           # майбутній торговий worker
services/ai/                # майбутній AI worker
packages/exchanges/mexc/    # адаптер біржі
packages/strategies/        # логіка стратегій
packages/indicators/        # індикатори
packages/risk/              # незалежна перевірка ризику
packages/backtesting/       # історична симуляція
configs/strategies/         # пресети стратегій
configs/risk-profiles/      # профілі ризику
configs/presets/            # інші пресети
configs/prompts/            # версії AI-промптів
infra/docker/               # майбутня Docker-конфігурація
tests/unit/                 # тести розрахунків та інваріантів
tests/integration/          # перевірки взаємодії компонентів
tests/contract/             # перевірки API та схем
tests/e2e/                  # наскрізні сценарії
docs/                       # специфікації й плани
```

Порожні папки містять лише `.gitkeep`, щоб Git зберігав структуру. `.gitignore` виключає локальні секрети, залежності, кеші, ринкові дані й результати запусків.

## Статус

Документація описує цільову поведінку, а не реалізовані можливості. Перед розробкою адаптера треба перевірити чинну документацію та доступність MEXC Futures API, правила інструментів і торгових операцій. До проходження відповідних етапів roadmap не позначати жодну функцію як готову.
